# pocock-writing-agents

Rivede una skill regola per regola con le indicazioni di Matt Pocock sulla scrittura per agenti e le aggiunte di Theo, poi propone un piano di riscrittura. Parte solo quando la chiami per nome.

Fa parte della [Prompt Library di CH Labs](https://www.cryptohelvetia.com/ch-labs/prompt-library), dove la pagina di riferimento è [Audit a skill with Pocock's writing rules](https://www.cryptohelvetia.com/ch-labs/prompt-library/skills/pocock-writing-agents). Il repo contiene una copia della skill, rigenerata a ogni aggiornamento della libreria.

## Installare

In Claude Code aggiungi una volta il marketplace e installa il plugin.

```
/plugin marketplace add MicheDada21/ch-labs-skills
/plugin install pocock-writing-agents@ch-labs-skills
```

Da shell i comandi sono `claude plugin marketplace add MicheDada21/ch-labs-skills` e `claude plugin install pocock-writing-agents@ch-labs-skills`. Nell'app desktop premi + accanto al campo del prompt, apri Plugins, aggiungi il marketplace `MicheDada21/ch-labs-skills` con Add marketplace e poi il plugin con Add plugin.

Per avere tutte le skill della libreria installa `tutte-le-skill@ch-labs-skills`. Con altri agenti copia la cartella `skills/pocock-writing-agents` tra le skill dell'agente, per esempio in `~/.codex/skills/pocock-writing-agents`.
